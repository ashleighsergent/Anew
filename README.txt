FASTEST WAY TO SUBMIT
1. Open index.html in Chrome to review.
2. Replace the cropped images in /assets with the original brand photography if you have it.
3. If your submission platform accepts a folder, upload the whole folder.
4. If it asks for a single file, keep the assets folder next to index.html and zip the folder.

IMPORTANT
The supplied reference was a screenshot rather than the original source assets, so the included image crops are taken directly from that screenshot to preserve the visual direction. For a final production build, swap them for the original high-resolution photography/product cut-outs.
